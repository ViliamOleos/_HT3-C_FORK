# HT3-C

The HT3 Programming Language being written in C. Current standard is C23.

Available for both Linux and Windows. To compile for windows, define the `COMP_WINDOWS` macro.

The original build method was custom and I currently do not have access to it, but a simple compiler command compiling all source files under `src\` _(recursively, of course)_ should suffice. Original compiler is GNU GCC.
